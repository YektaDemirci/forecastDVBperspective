# Dynamic Beam Hopping for DVB-Based LEO Networks

This repository contains the Python forecasters and supporting scripts for dynamic beam hopping presented in:

> *"The Impact of Demand Forecasting on Delay and Jitter in DVB-Based Beam-Hopping LEO Networks"*

## Dependencies

The scripts require **ns-3** and **sns-3** (SNS3 Satellite module) source codes:

- [ns-3](https://github.com/nsnam/ns-3-dev-git)
- [sns3-satellite](https://github.com/sns3/sns3-satellite)
